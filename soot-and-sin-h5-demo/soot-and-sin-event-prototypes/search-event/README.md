# 搜刮事件 Demo

直接開啟 `index.html` 即可試玩，不需要伺服器或套件。

流程：進入場景 → 雙人投票 → 黑霧幻燈片判定 → 結果與物品確認 → 繼續深入／分配物資／轉入戰鬥事件。

幻燈片會依當次機率生成物資、精品、神器、怪物、強大怪物與使徒；停在中央的底片就是實際結果。搜索不會落空，只會取得物資或進入戰鬥。

同名物資會堆疊數量。食物只能在藏匿處回血，不會出現在戰鬥中；武器與醫療用品會成為戰鬥行動。

搜索物資池分成武器、食物與醫療用品三類。

正常停止會送出 `scavenge-complete`；遭遇怪物則送出 `battle-event-requested`，並把待領物資存入 `window.pendingScavengeCombat`。
