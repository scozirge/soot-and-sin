# 章節選擇介面原型

直接開啟 `index.html`。目前僅保留定案的「電報案卷」介面，沒有版本切換或測試控制列。

- 左側只顯示當前章與主角，不顯示未登場章節或章節進度。
- 「序節」是人物檔案，顯示露西亞・艾弗里的背景、屬性與初始道具。
- 「第一節／煤灰車站」是唯一已解鎖的小節，使用強煤灰遮蔽的手繪場景。
- 其餘五個小節只顯示封印記號，不揭露名稱、地點、圖片或劇情文字。
- 人物資料與第一人稱內心獨白皆可上下拖曳閱讀；獨白會快速逐字輸出。

執行 `node validate.cjs` 驗證桌面、窄桌面與手機版面及互動；執行 `node capture-previews.cjs` 更新預覽截圖。
