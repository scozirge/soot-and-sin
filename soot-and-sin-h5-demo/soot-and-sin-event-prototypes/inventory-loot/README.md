# 物資整理獨立原型

開啟 `index.html` 即可遊玩。

- 「搜索所得」是無容量限制的上方暫存托盤；拖回去的物資會排在最後。
- 角色背包使用格狀排列，可在兩區之間拖曳物資。
- 拖曳途中按 `R` 會以抓取格為中心旋轉。
- 金色預覽可以放置；紅色預覽代表越界或碰撞。
- 將相同物資拖到一起會合併數量。
- 搜索結果建立時會自動把相同道具整理成一疊。
- 按住 `Shift` 開始拖曳堆疊，可拆出一半並放到其他位置。
- 滑鼠指向時顯示名稱、類型、功能、數量與佔格，拖曳中隱藏。
- 道具圖會跟著格子旋轉；食物、醫療品較小，工具類較大。
- 舊式提燈佔 8 格，鐵製鑰匙佔 2 格且使用較小圖像。
- 只有道具與背包，不含裝備中的武器、防具欄位。
