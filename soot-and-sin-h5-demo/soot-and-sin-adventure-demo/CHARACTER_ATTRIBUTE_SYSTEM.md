# 《煤灰與惡》角色屬性系統

## 1. 文件範圍

本文件記錄角色屬性的正式分類與作用。各角色的實際數值、成長幅度與計算公式由角色資料另行填寫。

## 2. 主要屬性

| 屬性 | 作用 |
| --- | --- |
| 生命 | 角色目前可承受的傷害；生命歸零時角色死亡。 |
| 背包格 | 決定角色背包共有多少格可放置道具。 |

## 3. 附屬性

| 屬性 | 作用 |
| --- | --- |
| 體力 | 影響角色的生命與背包格大小。 |
| 力量 | 影響使用物理攻擊武器造成的傷害。 |
| 搜查 | 影響搜尋物資時的結果。 |
| 魅力 | 影響交易費用與對話說服成功率。 |

## 4. 屬性關係

- 生命與背包格是角色在冒險中直接使用的主要屬性。
- 體力、力量、搜查與魅力是影響主要數值或玩法判定的附屬性。
- 體力同時影響生命與背包格；力量只作用於物理攻擊武器的傷害。
- 搜查用於物資搜尋；魅力同時作用於交易與劇本中的說服判定。
