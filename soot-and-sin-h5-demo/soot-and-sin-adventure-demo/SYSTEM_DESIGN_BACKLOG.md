# 《煤灰與惡》待設計系統清單

本清單只追蹤會影響整體遊戲框架的大方向問題，不列畫面、演出、單一事件內容、個別物品或細部數值。問題定案後應移入正式規格，並從本清單刪除。

已確定規則見 [`CHAPTER_SYSTEM_PLAN.md`](CHAPTER_SYSTEM_PLAN.md)、[`ECONOMY_AND_ITEM_SYSTEM.md`](ECONOMY_AND_ITEM_SYSTEM.md) 與 [`WORLDVIEW_AND_CHAPTER_ART_DIRECTION.md`](WORLDVIEW_AND_CHAPTER_ART_DIRECTION.md)。

## 已確定，不再發散

- 首發版只有一名可玩主角；新主角屬於後續版本。
- 每個小節固定 13 點：7 劇本、2 休息、4 戰鬥；章末小節第 13 點為 BOSS。
- 下一事件類型在抵達前保持未知；進入小節後不能撤退。
- 小節依條件解鎖，可以跨小節來回推進；關鍵劇本採鏈式解鎖。
- 角色死亡會重置目前章的背包、線索與小節狀態。
- 銀幣是最高級、可儲值取得的永久貨幣；死亡不會失去，所有章節與角色共用。
- 銅幣、銅製品、寶石與吊飾屬於占用背包的精品；多數商人接受銅幣。
- 道具分為精品、食物、武器、防具、飾品與特殊道具；關鍵道具是可附加於任何道具的保護標記。
- 武器放在背包中供戰鬥選用；防具只能穿一件；飾品留在背包中提供被動效果。
- NPC 同行者不搶物資、不參與戰利品分配，也不與玩家交易。

## P0：核心框架製作前必須定案

### 1. 劇本推進與重複探索

- [ ] 關鍵劇本的抽選、優先順序與最低推進保障採用哪一套原則。
- [ ] 一般劇本重複時，是允許原樣重現、使用短版結果，還是準備少量變體。
- [ ] 小節「完全完成」與下一章解鎖分別需要哪些類型的條件。
- [ ] 玩家卡住時，提示應介入到什麼程度，才能保留探索感又避免盲目重刷。

### 2. 戰鬥框架

- [ ] 戰鬥的主要決策循環與玩家每次行動需要管理的核心資源。
- [ ] 生命、心智、力量、魅力與智慧各自影響哪些主要系統。
- [ ] 部位破壞是所有敵人的共通核心，還是只用於代表性怪物與 BOSS。
- [ ] 銀製武器與銀製彈藥的消耗，如何和永久銀幣經濟分開或連動。
- [ ] 無法撤退的前提下，明顯劣勢戰鬥要保留哪些翻盤或準備空間。

### 3. 背包、裝備與製作

- [ ] 背包採格狀尺寸、固定格數，還是更簡化的容量規則。
- [ ] 物品是否具有耐久、使用次數、修理與損壞系統。
- [ ] 銅製品、寶石與其他材料是直接交易，還是同時支援完整製作系統。
- [ ] 戰利品超過背包容量時，玩家可以替換、放棄或暫存到什麼程度。

### 4. 角色成長與信念

- [ ] 主角成長以章內裝備與資源為主，還是另有死亡後保留的永久能力。
- [ ] 神祇／信念傾向會影響能力、事件、BOSS、結局中的哪些層級。
- [ ] 同行 NPC 是戰鬥單位、支援能力、被動效果，還是純劇情角色。

### 5. 經濟框架

- [ ] 銀幣在遊戲內的非付費來源、主要消耗與取得節奏。
- [ ] 銀幣可購買的範圍，以及哪些核心內容不能只靠銀幣跳過。
- [ ] 銅幣與精品負責的交易層級，和銀幣之間是否存在固定兌換關係。
- [ ] 儲值銀幣如何避免破壞探索、死亡壓力與單機遊戲平衡。

## P1：垂直切片中驗證方向

### 6. 小節節奏與資源壓力

- [ ] 休息、搜查、一般劇本與戰鬥各自在一節中提供什麼策略作用。
- [ ] 重刷一個小節的資源收益，如何做到有成長感又不讓 BOSS 失去壓力。
- [ ] 一節 13 點的實際遊玩時間與四場戰鬥密度是否適合重複遊玩。

### 7. 劇本產量與重用

- [ ] 一個小節需要多少一般劇本與關鍵劇本，才能支撐預期重刷次數。
- [ ] 選擇分支對資源、線索與信念的影響深度，控制在什麼範圍才不會擴張製作量。
- [ ] 主角觀察、NPC 單向發言與玩家選項的固定事件模板是否足以建立角色印象。

### 8. 垂直切片內容範圍

- [ ] 垂直切片包含幾個小節、一般敵人、代表性部位破壞敵人與 BOSS。
- [ ] 垂直切片必須驗證哪些核心賣點，才足以決定是否進入完整製作。
- [ ] 垂直切片的目標遊玩時間、重刷次數與完成標準。

## P2：垂直切片成立後決定商品規模

### 9. 首發內容與平台

- [ ] 首發章節數、小節數、敵人數、BOSS 數、結局數與總遊戲時間。
- [ ] 正式存檔、異常恢復、控制器與 Steam Deck 支援範圍。
- [ ] 難度、輔助選項、語言與無障礙功能的首發範圍。

### 10. 商業與後續版本

- [ ] Steam 買斷價格、銀幣儲值與遊戲內取得三者的商業定位。
- [ ] Demo 展示範圍與正式版必須承諾的核心內容。
- [ ] 新主角版本是否沿用現有系統、銀幣資產與世界進度。
