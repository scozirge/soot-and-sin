# 《煤灰與惡》必做設計清單

本清單只列出使用者已明確提出、遊戲確定需要的設計項目，不主動增加未提及的系統。每一項代表一份可獨立補完的設計內容；規則已正式記錄者標為完成，只有分類但尚未補齊內容者保留未完成。

正式規格見 [`CHARACTER_LUCIA_AVERY.md`](CHARACTER_LUCIA_AVERY.md)、[`CHARACTER_ATTRIBUTE_SYSTEM.md`](CHARACTER_ATTRIBUTE_SYSTEM.md)、[`TALENT_SYSTEM.md`](TALENT_SYSTEM.md)、[`CHAPTER_SYSTEM_PLAN.md`](CHAPTER_SYSTEM_PLAN.md)、[`COMBAT_REST_SEARCH_RULES.md`](COMBAT_REST_SEARCH_RULES.md)、[`ECONOMY_AND_ITEM_SYSTEM.md`](ECONOMY_AND_ITEM_SYSTEM.md) 與 [`WORLDVIEW_AND_CHAPTER_ART_DIRECTION.md`](WORLDVIEW_AND_CHAPTER_ART_DIRECTION.md)。

## P0：角色、貨幣與道具

### 1. 角色設計

- [x] 主角基本設定：露西亞的身分、背景、個性與初始道具。
  - 主角為露西亞・艾弗里，是古老皇室後代與少數受過高等教育的知識分子，現為胡桃木生存組織的小家庭成員。
  - 個性沉穩、聰明、善於學習，具有探索未知與追求知識的慾望；態度正向並具領導魅力與強韌精神。
  - 學習以外的時間，她會跟隨另一名胡桃木成員前往車站搜索可用物資。
  - 附屬性為體力 4、力量 4、搜查 7、魅力 8。
  - 主要屬性為生命 70、背包格 34、肉搏傷害加成 +20%、非銀幣商品交易費用折扣 24%、說服成功率 24%。
  - 初始道具為油燈、學院制服、寶石吊墜、水壺、切肉刀與麵包。
- [x] 屬性設計：主要屬性與附屬性的分類及用途。
  - 主要屬性為生命、背包格、肉搏傷害加成、非銀幣商品交易費用折扣與說服成功率。
  - 生命基礎值為 50，每點體力增加 5；背包格基礎值為 30，每點體力增加 1。
  - 每點力量增加 5% 肉搏武器傷害；每點魅力降低 3% 非銀幣商品交易費用，並提供 3% 說服成功率。
  - 搜查影響搜尋物資，但實際換算規則仍待規劃。
- [ ] 技能設計：露西亞可以使用或取得的角色技能。
- [x] 天賦系統規則：永久能力、角色初始專屬天賦，以及遊玩取得的額外天賦。
  - 天賦獲得後不會因角色死亡、章節背包重置或進入新章而失去。
  - 每名角色具有初始專屬天賦；其他額外天賦必須在遊玩過程中取得。
- [x] 露西亞初始專屬天賦「魅力」：強化說服，並在安全區取得夥伴補給。
  - 說服成功率額外增加 5 個百分點；配合魅力屬性的 24%，起始總值為 29%。
  - 進入安全區事件時，夥伴會提供 1 件食物或醫療用品。
- [ ] 額外天賦設計：遊玩中可取得的天賦內容與取得條件。

### 2. 貨幣設計

- [x] 銀幣設定：最高級貨幣、可儲值取得、死亡保留、跨章節與角色共用，以及銀的世界觀功能。
  - 銀幣是最高級且最通用的貨幣，幾乎能購買所有用品，也能透過儲值取得。
  - 銀幣不占背包，角色死亡後不會失去，由所有章節與未來角色共用。
  - 所有怪物都懼怕銀；銀能驅散超自然力量，也能製作子彈、冷兵器與機械零件。
  - 銀具有皇室傳承與信仰價值，末日後十分稀有。
- [x] 銅幣與精品設定：銅幣屬於可堆疊精品，會占用背包，多數商人接受交易。
  - 銅製品、寶石、吊飾與貴重小物都屬於精品道具，不計入永久貨幣。
  - 銅幣可堆疊但仍占用背包，多數一般商人接受銅幣交易。
  - 銅製品可以作為器械材料；精品會隨目前章的死亡重置規則清除。
- [x] 銀幣取得與消耗：遊戲內取得來源、儲值取得方式及可以購買的用品範圍。
  - 銀幣會在劇本事件中低機率出現，也會在擊敗大型 BOSS 後取得，並可透過儲值獲得。
  - 銀幣可購買強力道具，或用來解鎖角色造型與隊友。
  - 使用銀幣時把要支付的數量放入交易付款區，對方接受出價後才完成交易。
- [x] 商人交易規則：銀幣、銅幣、寶石、吊飾與其他精品的交易方式。
  - 商人顯示可販賣道具；玩家把想要的物品拖入待購買區，再查看銀幣與銅幣價格。
  - 玩家把貨幣或具有價值的道具拖入待付出區，系統即時加總目前提供的銀價值與銅價值。
  - 銀與銅分開計算且不能互相轉換；每一種被要求的價值都必須個別達標，超過要求仍可成交。
  - 除關鍵道具外，任何交易價值不為 0 的道具都能放入待付出區交易。

### 3. 道具設計

- [x] 道具分類規則：精品、食物、醫療用品、武器、防具、飾品、特殊道具，以及可附加於任何道具的關鍵道具標記。
  - 食物只能在休息事件中使用；醫療用品同為恢復型消耗品，但可以在戰鬥中使用。兩者的具體效果仍待規劃。
  - 武器留在背包並可於戰鬥中任意選用。
  - 防具同時只能穿一件，多餘防具仍占背包；飾品留在背包中提供被動效果。
  - 特殊道具沒有一般使用功能，只負責觸發劇本效果。
  - 關鍵道具是附加標記，任何類型道具都可能成為關鍵道具，且不能主動丟棄或販售。
- [ ] 精品設計：銅幣、銅製品、寶石、吊飾及其他精品清單。
- [ ] 食物設計：各種食物、可恢復的角色狀態與恢復數值。
- [ ] 醫療用品設計：可在戰鬥中使用的醫療用品清單與恢復數值。
- [ ] 武器設計：放在背包並可於戰鬥中選用的武器清單與效果。
- [ ] 防具設計：同時只能穿一件的防具清單與效果。
- [ ] 飾品設計：放在背包中即可生效的飾品清單與被動效果。
- [ ] 特殊道具設計：本身沒有一般功能、只用於觸發劇本的道具清單。
- [ ] 關鍵道具設計：各章不可任意丟棄或販售的重要劇本道具。
- [x] 背包操作規則：格狀背包、拖曳放置、旋轉與手動堆疊。
  - 道具依形狀占用背包格，必須放入未被其他物品占用的格子。
  - 整理時可拖曳道具，並按 R 旋轉形狀。
  - 同種道具不會自動合併；拖到相同道具上才會堆疊數量。
  - 搜查與戰鬥物資都進入玩家的個人背包，不設隊友競爭或公共分配。
- [ ] 各道具背包資料：占用格數、形狀、可否堆疊及裝備狀態。

## P1：章節、小節與事件

### 4. 章節與小節設計

- [x] 章節結構規則：首發單一主角、同章同一時期，小節代表不同時間與地點的冒險。
  - 首發版本只使用露西亞一名可玩主角，新的主角留到後續版本。
  - 同一章固定為同一主角與連續故事時期，不在章內切換相隔多年的時間線。
  - 每個小節是不同時間與地點的一次完整冒險；已解鎖小節可以重複遊玩。
  - 同一主角的不同章仍是獨立故事實例，章內道具、線索與小節狀態互不共用。
- [ ] 各章基本資料：章名、故事時期、主要地區、主角初始狀態與初始道具。
- [ ] 各章小節清單：每個小節的名稱、時間、地點與冒險目的。
- [x] 解鎖系統規則：小節依條件開放、可跨小節來回推進，下一章需線索與 BOSS 勝利。
  - 每章初始只開放第一小節；其他小節依線索、關鍵劇本或其他小節狀態解鎖，不按照序號。
  - 小節可以先解鎖後續小節，再由後續取得的條件回頭完成原小節。
  - 已解鎖只代表可以進入，不代表關鍵劇本已全部完成；所有已解鎖小節均可重玩。
  - 下一章必須同時取得指定關鍵線索並擊敗本章 BOSS。
- [ ] 各章實際解鎖條件：每個小節、BOSS 小節及下一章所需的具體線索與劇本階段。
- [x] 死亡與結算規則：死亡重置本章背包、線索與小節狀態；銀幣與其他永久紀錄保留。
  - 正常走完 13 個事件點後結算，保留目前章的背包物資，本次銀幣加入永久資產。
  - 角色死亡會清空目前章的背包道具、有效線索與小節解鎖，只保留第一小節。
  - 銀幣、已解鎖章節、已完成章節、首次 BOSS 勝利與已讀檔案不受影響。
  - 死亡後主角失去本輪記憶，但玩家仍能保留輪迴外的已讀資訊。

### 5. 小節事件設計

- [x] 十三事件點規則：7 個劇本、2 個休息、4 個戰鬥，下一事件在抵達前保持未知。
  - 休息事件一固定隨機出現在第 4–6 點，休息事件二固定隨機出現在第 10–12 點。
  - 其他位置隨機分配 7 個劇本事件與 4 個戰鬥事件，尚未抵達的事件不顯示類型。
  - 章末小節第 13 點固定為 BOSS，並計入四個戰鬥事件。
  - 進入小節後不能撤退，只能完成全部事件點或因主角死亡而結束。
- [x] 事件節奏規則：劇本、戰鬥、休息與搜查的目標時間。
  - 一般劇本事件約 15–30 秒，一般戰鬥以 2 分鐘內結束為目標。
  - 純休息為 10 秒，搜查為 30 秒；休息不應強迫等待，完成操作後可以立即結束。
  - 完成第 13 點才正常結算小節，保留章內背包並把取得的銀幣加入永久資產。
- [ ] 一般劇本事件：每個小節可重複抽取的一般劇本事件池。
- [x] 關鍵劇本與線索規則：鏈式解鎖、單次觸發上限、跨小節條件與提示方式。
  - 每個小節有分階段的關鍵劇本鏈，完成目前階段後才開放下一階段。
  - 一次小節冒險最多出現 3 次關鍵劇本；條件未滿足或未抽中時可以少於 3 次或完全不出現。
  - 新解鎖階段可能在同一次小節後半出現，也可能留到下次重玩。
  - 劇本會暗示遺漏線索可能在哪個小節；介面只標示「尚未完成」，不公開正確順序與條件。
- [ ] 各小節關鍵劇本內容：實際劇本鏈、觸發條件、關鍵線索與跨小節提示。
- [x] 休息事件規則：固定出現位置、10 秒節奏、食物使用與立即結束。
  - 每節第一個休息事件隨機位於第 4–6 點，第二個隨機位於第 10–12 點。
  - 食物只能在休息事件中使用；食物的實際恢復對象與數值仍待規劃。
  - 純休息目標為 10 秒，玩家完成操作後可以立即結束，不強迫等待倒數。
- [x] 搜查事件規則：30 秒搜索、物資結果、怪物遭遇與暫存戰利品。
  - 搜查屬性會影響搜尋物資，但實際換算公式仍待規劃。
  - 搜查可以取得物資或遭遇怪物；遭遇戰鬥時先暫存當次物資，勝利後才進入背包整理。
  - 深入搜查時，威脅與高級物資機率會一起提高；實際機率仍需設計。
- [ ] 各小節休息與搜查內容：可用食物效果、物資池、遭遇池及實際機率。
- [x] 戰鬥事件配置規則：每節四場戰鬥，章末 BOSS 固定在最後一點。
  - 一般小節在非休息位置隨機分配 4 個戰鬥事件。
  - 章末小節包含 3 個一般戰鬥，第 13 點固定為 BOSS，合計仍為 4 個戰鬥事件。
  - 尚未抵達戰鬥點前不公開該點是戰鬥，也不預告敵人。
- [ ] 各小節敵人配置：一般戰鬥敵人池、出現條件、敵人組合與章末 BOSS。

## P2：戰鬥、劇本與神祇

### 6. 戰鬥設計

- [x] 玩家戰鬥核心：即時倒數、行動耗時、武器與部位選擇。
  - 怪物會公開下一個行動、目標與剩餘時間，倒數結束後執行並選擇下一個行動。
  - 玩家行動需要時間，目前核心節奏約為 2–6 秒；完成後可以立即選擇下一個行動。
  - 攻擊時先選擇背包中的武器，再選擇怪物部位；不同部位具有不同命中率與傷害倍率。
- [x] 防禦與閃避規則：使用條件、操作鎖定與怪物攻擊結算。
  - 防禦與閃避只在怪物即將攻擊且剩餘時間足夠時使用。
  - 使用後會鎖定操作，等待該次怪物行動結算；防禦降低傷害，閃避避免該次命中。
- [x] 戰鬥道具規則：使用次數、醫療用品與食物限制。
  - 有使用次數的武器或道具在行動完成後消耗一次，歸零後從行動列移除。
  - 食物只能在休息事件使用，不會出現在戰鬥行動列。
  - 醫療用品是正式的恢復型道具分類，可以在戰鬥中使用。
- [x] 怪物部位破壞規則：部位門檻、停用、行動限制與即死部位。
  - 每個部位可設定命中率、傷害倍率、破壞門檻與破壞效果；已破壞部位不能再次選取。
  - 依賴已破壞部位的怪物行動會被取消或從行動池移除。
  - 即死部位達到門檻時直接結束戰鬥；其他部位破壞後怪物仍可繼續戰鬥。
- [x] 戰鬥勝負與戰利品：死亡、勝利及搜查戰鬥的物資結算。
  - 主角生命歸零時死亡並套用本章死亡重置規則。
  - 勝利後戰利品由玩家選擇並整理到個人格狀背包，NPC 不參與分配。
  - 搜查觸發的戰鬥勝利後，同時結算戰前暫存的搜查物資。
- [ ] 裝備戰鬥效果：武器、防具與飾品如何影響戰鬥。
- [ ] 敵人設計：怪物屬性、行動、可攻擊部位與部位破壞效果。
- [ ] 銀與戰鬥平衡：銀對超自然力量的效果、一般戰鬥約兩分鐘及 BOSS 戰節奏。

### 7. 劇本與世界觀設計

- [x] 劇本互動方式：主要由 NPC 發言，主角以第一人稱觀察和玩家選項表現個性。
  - 不製作多輪大型對話樹，主要由 NPC 帶出事件與資訊。
  - 主角平時以簡短的第一人稱觀察持續建立印象，只在需要玩家決定時明確回應。
  - 選項必須是露西亞可能說出的話或採取的行動，不能使用沒有個性的功能文字。
  - 分支以短暫分開、立即匯流為主，結果可改變物品、線索、傷勢或隱藏信念傾向。
- [x] 世界觀核心：維多利亞後末日、信念形成神祇、死亡回歸與神祇不分善惡。
  - 世界是帶有魔法與機械的維多利亞後末日，主調為黑色幽默、血腥暴力、肉體恐怖與慾望，溫馨內容相對稀少。
  - 神祇由強烈信念凝聚而成，不以善惡分類，只反映信徒與玩家深層的渴望。
  - 被神祇看中的主角會死亡回歸並失憶，玩家透過反覆選擇逐漸把主角塑造成某種信念期待的樣子。
  - BOSS 是阻擋主角成形的必要障礙，可以是信徒、使徒、怪物、制度執行者或普通人。
- [ ] 主角語氣設計：露西亞的第一人稱觀察、選項語氣與行為邊界。
- [ ] 神祇設計：各神祇代表的信念、渴望及主角選擇造成的傾向。
- [ ] 章節劇情設計：每章主線、NPC、關鍵事件、BOSS 的阻礙意義與可能結局。
