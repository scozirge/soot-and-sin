# 《煤灰與惡》待設計系統清單

本文件只追蹤尚未定案的系統問題。已確定的章節規則以 [`CHAPTER_SYSTEM_PLAN.md`](CHAPTER_SYSTEM_PLAN.md) 為準；問題定案後應移入正式規格，並從本清單刪除。

## 已確定，不再發散

- 首發版只有一名可玩主角；新主角屬於後續版本。
- 每個小節固定 13 點：7 劇本、2 休息、4 戰鬥；章末小節第 13 點為 BOSS。
- 下一事件類型在抵達前保持未知。
- 一般劇本事件約 15–30 秒，戰鬥約 2 分鐘內，純休息 10 秒，搜查 30 秒。
- 進入小節後不能撤退；完成 13 點後結算。
- 正常結算保留背包物資與本次取得的貨幣。
- NPC 同行者不搶物資、不參與戰利品分配，也不與玩家交易。
- 所有怪物都懼怕銀，銀能驅散超自然力量，並可製作子彈、冷兵器、機械義肢與驅邪機械的重要構件。
- 銀具有皇室傳承且因末日後難以開採、精煉而稀有；銀幣、銀錠與皇家銀器可作為高價交易貨幣。
- 小節依條件解鎖，可跨小節來回推進；未完成小節只顯示「尚未完成」。
- 關鍵劇本採鏈式解鎖，每次小節最多出現 3 次，但不保證每輪都觸發。

## P0：垂直切片製作前必須定案

### 1. 貨幣與經濟

- [ ] 高價銀貨幣的正式名稱、單位、面額與 UI 圖示。
- [ ] 一般食物、休息與低價物資也直接使用銀，還是另有銅幣、配給票或以物易物。
- [ ] 銀幣、銀錠、皇家銀器與可熔銀料是否共用同一貨幣數值。
- [ ] 貨幣的主要來源、每節預期收入與持有上限。
- [ ] 貨幣可以購買、修理、恢復或解鎖哪些內容。
- [ ] 貨幣是章內資源還是永久資源；死亡後是否清除。
- [ ] 玩家要如何辨別銀的純度、皇家印記、剪邊與鍍銀偽幣。
- [ ] 是否存在商人、固定價格、議價或以物易物；NPC 隊友交易仍永久排除。

### 2. 關鍵劇本抽選與保底

- [ ] 符合條件的關鍵劇本如何和一般劇本競爭七個劇本槽。
- [ ] 新階段在同一次小節後半再次出現的權重。
- [ ] 連續幾次完整探索沒有推進後啟動保底。
- [ ] 多個關鍵劇本同時符合條件時的優先順序。
- [ ] 已取得的一次性線索再次抽中時改成什麼回饋。

### 3. 一般劇本的重複處理

- [ ] 已讀一般劇本是否可以原樣重複。
- [ ] 重複事件是否縮短文字、快速結算或產生變體。
- [ ] 一般劇本池耗盡時如何避免短時間連續重複。

### 4. 小節完成與跨小節相依

- [ ] 小節「完全完成」的精確資料條件。
- [ ] 每個小節最多依賴多少其他小節。
- [ ] 每節允許幾組主要的回流關係。
- [ ] 如何自動驗證沒有封閉循環或永久無法到達的關鍵劇本。
- [ ] 玩家卡住多久後，劇本提示與「尚未完成」標示是否變得更明確。

### 5. 死亡後的重跑體驗

- [ ] 已讀劇本能否略過、加速或直接顯示短版結果。
- [ ] 玩家永久筆記保留哪些線索來源與死亡紀錄。
- [ ] 重跑已知內容是否提供事件權重、路線或操作上的加速。
- [ ] 貨幣死亡後是否清除。
- [ ] 從死亡到重新操作的目標時間。

### 6. 戰鬥完整規格

- [ ] 即時倒數、玩家行動時間、暫停與遊戲速度的正式規則。
- [ ] 生命、命中、傷害、防禦、閃避、狀態與心智的計算方式。
- [ ] 部位生命、破壞門檻、即死部位與已破壞部位停用規則。
- [ ] 銀製子彈、冷兵器、鍍層與刻紋分別如何驅散怪物能力，以及銀純度如何影響效果。
- [ ] 銀既是高價貨幣又是戰鬥材料時，如何避免玩家因捨不得消耗而完全不用銀製武器。
- [ ] 如何確保一般戰鬥在約 2 分鐘內結束。
- [ ] BOSS 是否同樣以 2 分鐘內為目標，或使用獨立時間規格。
- [ ] 無法撤退時，玩家遭遇明顯打不過的戰鬥要如何保有決策空間。

### 7. 部位破壞與劇本連動

- [ ] 哪些代表性敵人的部位會掉落事件道具或關鍵線索。
- [ ] 不同部位破壞是否改變戰後事件、NPC 反應或後續小節。
- [ ] 特殊部位物是否占用背包，以及死亡、使用與重複取得規則。
- [ ] 同一敵人不同擊殺方式需要多少額外劇本與美術內容。

### 8. NPC 同行者定位

- [ ] 同行者是完整自動戰鬥單位、支援行動、被動能力或純劇情角色。
- [ ] 同行者能否受傷、死亡、失控或暫時離隊。
- [ ] 同行者狀態是否跨小節保留，以及死亡回歸後如何重置。
- [ ] 如何讓同行者有存在感，又不重新引入隊伍管理與多人經濟。

### 9. 戰利品與個人背包

- [ ] 戰利品是全部取得，還是受背包容量限制後選擇。
- [ ] 背包已滿時能否丟棄、替換、暫存或直接失去物品。
- [ ] 堆疊、旋轉、物品尺寸、耐久與使用次數的正式規格。
- [ ] 完成小節後哪些物品可帶入同章其他小節。
- [ ] 進入新章時的初始道具與清除規則。

## P1：在垂直切片中測試後定案

### 10. 休息與搜查

- [ ] 純休息 10 秒恢復多少生命、心智或狀態。
- [ ] 玩家在休息期間能否整理背包與使用食物。
- [ ] 30 秒搜查的操作方式、掉落池、風險與遭遇戰機率。
- [ ] 休息與搜查是否為二選一，選擇後能否提前結束演出。

### 11. 物資壓力與重刷平衡

- [ ] 重刷一個小節的平均物資淨收益。
- [ ] 如何避免無限重刷讓 BOSS 完全失去壓力。
- [ ] 消耗品、武器耐久、醫療與食物的預期消耗速度。
- [ ] 玩家過早解鎖 BOSS 時要提供多少危險提示。

### 12. 主角屬性與心智

- [ ] 生命、心智、力量、魅力與智慧各自影響哪些系統。
- [ ] 屬性是固定角色特質、章內成長，還是存在永久成長。
- [ ] 心智降低的來源、階段效果與恢復方法。
- [ ] 心智是否改變選項、畫面、戰鬥行為或神祇傾向。

### 13. 神祇／信念傾向

- [ ] 首發版有幾個隱藏信念方向。
- [ ] 哪些選擇與行為會改變傾向。
- [ ] 傾向何時影響能力、事件、BOSS 意義與結局。
- [ ] 玩家何時開始察覺異常，但仍不被 UI 直接解說世界真相。
- [ ] 各路線共用內容與專屬內容的比例上限。

### 14. 首節教學與資訊介面

- [ ] 角色序節與煤灰車站分別教哪些功能。
- [ ] 第一個小節是否只展示部分系統，避免一次教完。
- [ ] 線索筆記、尚未完成、死亡損失與異常提示的資訊層級。
- [ ] 如何讓玩家理解重刷目的，又不揭露完整解鎖公式。
