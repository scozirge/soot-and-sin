# 《煤灰與惡》世界觀定錨與章節美術方向

目前章節介面原型見 [`../soot-and-sin-event-prototypes/chapter-selection/index.html`](../soot-and-sin-event-prototypes/chapter-selection/index.html)。

> 玩家前期只會把章節介面理解為「正在遊玩某位主角的破碎劇本」。介面不得直接說出神祇、死亡回歸、失憶、塑形或神祇傾向；這些設定只能先以肖像錯位、底片殘影、異常印章與黑暗觀眾席等視覺伏筆存在，等劇情逐步拼出世界觀後再解讀。

## 1. 世界觀核心

### 1.1 神祇的本質

- 世界中存在多位神祇。
- 神祇主要由強烈、持續且足以改變現實的信念凝聚而成。
- 神祇不是以善惡分類的陣營，也不代表傳統意義上的正義或邪惡。
- 神祇真實反映信徒與玩家深層的渴望；同一種渴望既可能救人，也可能造成殘酷結果。
- 神祇對人的「期待」是一種理想形狀：希望某個人最終成為符合該信念的人。
- 神祇可以彼此矛盾，但不以簡化的光明／黑暗、善／惡二元對立呈現。

### 1.2 潛力信徒與主角

- 正式首發版本只描寫一名可玩主角，所有章節都以這名角色為故事核心。
- 主角具有既定的成長背景、個性、關係、慾望與行為邊界；NPC 與同行者不屬於可玩主角。
- 玩家不是把主角當成空白化身，而是在既有性格基礎上替他做選擇。
- 選項必須是「這個人可能做出的不同決定」，不能為了讓玩家自由而讓角色突然違反核心性格。
- 不同選擇會讓主角逐漸靠近不同神祇所代表的信念，並產生不同事件、關係、能力、BOSS 意義與結局。
- 玩家最後走向哪位神祇，應由一連串選擇與實際行為形成，不能只靠結尾的一次陣營選單決定。
- 新的可玩主角屬於後續版本內容，必須以新的故事範圍獨立規劃，不預先擴張首發劇本。

### 1.3 死亡回歸

- 被神祇看中潛力的主角會獲得死亡回歸。
- 死亡回歸不是單純的遊戲讀檔，而是世界觀中真實發生的反覆塑形。
- 主角死亡後會失去該輪迴的記憶，並從該章第一小節重新開始。
- 玩家保留上一輪的經驗，因此玩家遊玩的過程就是反覆死亡、重新選擇，直到主角完成某位神祇期待的形狀。
- 神祇或位於輪迴之外的存在保留每次嘗試留下的痕跡；這是 UI 可以保存已讀劇情與歷史紀錄、角色卻仍然失憶的敘事依據。
- 死亡不是世界線被取消。每次失敗都曾經發生，只是主角無法正常記得。

### 1.4 玩家知識與角色知識

必須分開處理兩種知識：

| 知識層 | 持有者 | 死亡後 | 用途 |
| --- | --- | --- | --- |
| 角色當輪記憶 | 主角 | 清除 | 事件條件、對話、當輪線索與小節解鎖 |
| 玩家／神祇紀錄 | 玩家與輪迴外視角 | 保留 | 已讀檔案、死亡歷史、曾見選項與世界觀整理 |

玩家可以記得某條道路危險，但下一輪主角不能直接在對話中引用自己已遺忘的經歷。若要讓主角產生既視感、夢境或身體記憶，必須由劇本明確賦予，不能由永久圖鑑自動視為角色知情。

### 1.5 BOSS 的意義

- 每章 BOSS 是阻擋主角成為某種「神祇期待形狀」的必要障礙。
- BOSS 不等於邪惡角色，也不一定是怪物。
- BOSS 可以是其他神祇的信奉者、使徒、怪物、制度執行者、普通人、朋友、家人或主角仍不願放下的關係。
- 擊敗 BOSS 可能代表殺死、制服、背叛、拒絕、放棄、揭露或完成一場無法回頭的選擇；不必每次都用道德正當化。
- 同一名 BOSS 在不同神祇路線中可以具有不同意義：必須消滅的阻礙、證明信念的祭品、需要保護的人，或使主角拒絕神祇期待的最後機會。
- BOSS 美術不能一律使用「邪惡紅色骷髏」標記，否則會錯誤替玩家先做道德判斷。

### 1.6 銀、怪物與超自然力量

- 所有怪物都本能地懼怕銀；即使怪物的來源、信仰與形態不同，也不存在完全免疫銀之基本排斥性的例外。
- 銀能驅散、削弱或暫時阻斷超自然力量。實際效果可依銀的純度、接觸方式、使用量與目標強度有所差異，但不能退化成只有特定怪物才有效的普通屬性弱點。
- 銀可以製成子彈、冷兵器、武器鍍層、刻紋與結界零件；不必把整件武器都做成銀，關鍵接觸面或導引結構含銀即可產生效果。
- 銀是機械義肢、精密機械與驅邪機械的重要材料，尤其用於需要穩定傳導、隔絕或控制超自然力量的接點與內部構件。
- 銀具有皇室傳承與制度權威。皇室長期控制高純度銀料、鑄幣、銀器與相關工藝，帶有皇家印記的銀製品也可成為露西亞身分與家族歷史的劇情證據。
- 末日後礦場、精煉設施與皇室工坊大量毀滅，現存銀料又持續被武器、義肢、醫療與防護設施消耗，因此銀兼具實用性、稀有性與可回收性。
- 銀幣、銀錠與可驗純度的皇家銀器是跨組織接受的高價交易貨幣；其價值同時來自貴金屬本身、皇室標準重量與對抗怪物的實際用途。
- 普通人初期只需理解「銀能保命且很值錢」，銀為何能驅散超自然力量可留到後續劇情逐步揭露。

## 2. 敘事調性

### 2.1 時代與環境

- 背景是維多利亞時期美術語彙下的後末日世界。
- 城市仍殘留階級、禮教、宗教、工業與官僚制度，但都在災難後以扭曲方式繼續運作。
- 蒸汽、煤煙、煤氣燈、黑鐵、黃銅、舊木、教堂、工廠、貧民窟、醫療器械、死亡攝影與早期印刷構成主要視覺語言。
- 後末日不是只有廢墟，也包含「明明世界已經壞掉，人們仍認真維持荒謬日常」的黑色幽默。

### 2.2 內容比例

- 主調：黑色幽默、血腥暴力、肉體恐怖、慾望與不潔感。
- 次調：荒謬的官僚制度、失敗的禮儀、對死亡習以為常的日常。
- 稀有調性：溫馨、真誠、感人的關係片段。
- 溫馨內容因為稀少，應該以真正乾淨、安靜的畫面呈現，不再額外加上諷刺文字破壞情緒。
- 腥羶與性暗示應服務角色、權力、慾望或信仰，不以所有頁面持續堆疊裸露與血液；留白能讓真正殘酷的場面更有效。

## 3. 章節美術總概念：未完成聖徒陳列室

正式推薦名稱：**未完成聖徒陳列室**
英文工作名：**The Gallery of Unfinished Saints**

這是一個存在於死亡與下一次醒來之間的維多利亞暗房、停屍間、檔案室與神龕混合空間。它不必一開始明說屬於哪位神祇，只讓玩家感覺到「某種東西正在保存並觀看每一次嘗試」。

原本「煤灰案卷桌」的資訊架構保留，但重新賦予以下意義：

| 系統內容 | 美術物件 | 世界觀意義 |
| --- | --- | --- |
| 章 | 主角的死後紀念照與厚卷宗 | 神祇正在塑形的一段人生 |
| 小節 | 排在黃銅軌道上的玻璃底片 | 不同時間、地點的一次調查可能性 |
| 鎖定小節 | 尚未顯影的黑色玻璃底片 | 神祇尚未確認下一個試煉位置 |
| 線索 | 底片上的重影、手寫註記與暗紅棉線 | 輪迴外保留下來的觀測結果 |
| 道具 | 標本盤、證物袋與行囊托盤 | 只屬於本輪生命的物質 |
| 死亡 | 底片過曝、破裂並被蓋上退件章 | 這次塑形沒有達到期待 |
| 神祇傾向 | 肖像周圍逐漸形成的材質與構圖污染 | 玩家渴望正在被某個信念辨認 |
| BOSS | 擋在主角肖像與顯影光源之間的另一道影像 | 主角成形前必須處理的阻礙 |

## 4. 章節選擇畫面

### 4.1 第一層：死後肖像牆

章節列表不是普通卡片，也不是英雄選擇介面，而是一面掛滿維多利亞死後紀念照的牆。

- 每一章是一張主角肖像與一個下方卷宗抽屜。
- 肖像呈現角色在該章開始時的固定身分，而不是玩家自由捏出的形象。
- 同一主角的不同章使用相同面部特徵，但服裝、傷痕、日期、攝影背景與相框編號不同，表示這是獨立故事。
- 未解鎖章節是尚未完成感光的銀色玻璃，只能看見模糊人影。
- 已完成章節的相框不是變得光明神聖，而是出現某位神祇特有的完整構圖痕跡。
- 游標指向肖像時，眼睛、倒影或背景人物可以出現非常輕微的錯位，暗示這些紀錄正在回看玩家。

章節縮圖需顯示：

- 章序與章名。
- 主角姓名。
- 故事時期與主要地區。
- 已解鎖小節數。
- 當前狀態：`尚未成形／塑形中／終局可見／已完成一種形狀`。

避免使用 `善良路線 60%`、`邪惡路線 40%` 等文字。

### 4.2 第二層：三聯式顯影神龕

選取章節後，肖像牆中央打開成三聯式神龕：

```text
┌──────────────────────────────────────────────────────────────────────┐
│ 未完成聖徒陳列室               第 17 次顯影             返回肖像牆 │
├──────────────┬───────────────────────────────────┬───────────────────┤
│ 生前資料     │ 主角死後肖像／章名               │ 凝視留下的痕跡    │
│              │                                   │                   │
│ 主角         │       固定的角色核心形象          │ 尚未命名的信念    │
│ 年代         │                                   │ 反覆傾向：控制    │
│ 地區         │  [肖像周圍產生不同神祇材質痕跡]   │ 偶爾傾向：憐憫    │
│ 章節摘要     │                                   │                   │
├──────────────┴───────────────────────────────────┴───────────────────┤
│ 玻璃底片軌道：01──02──03──04──未顯影──[終局阻影]                  │
│                  所選小節的時間、地點、線索方向與進入按鈕          │
└──────────────────────────────────────────────────────────────────────┘
```

三個區域的敘事功能：

- **左翼「生前資料」**：提醒玩家這名主角原本是誰，守住既定性格與背景。
- **中央「未完成肖像」**：顯示目前選擇正在把角色塑造成什麼樣子。
- **右翼「凝視痕跡」**：提供神祇傾向回饋，但先顯示價值詞、材質與象徵，神名可隨劇情揭露。
- **下方「玻璃底片軌道」**：負責小節選擇，不與小節內的 13 事件點路線混在一起。

## 5. 小節的美術呈現

### 5.1 玻璃底片

每個小節是一片裝在黃銅框裡的濕版玻璃底片：

- 左上刻小節序號。
- 下方貼時間與地點的打字紙條。
- 底片中央使用該地點的模糊負片，不預告關鍵事件全貌。
- 已探索小節疊加刮痕、指紋與死亡次數，不使用完成勾號把它表現成一次性關卡。
- 可重玩狀態顯示 `再次顯影`，第一次進入顯示 `開始顯影`。
- 本輪取得新線索後，底片上會多出原本不存在的細節或手寫註記。

### 5.2 鎖定與條件解鎖

- 所有未解鎖小節收在黑色防光袋裡，只露出章內編號，不暗示實際解鎖先後。
- 任一小節滿足自己的線索與關鍵劇本條件後，即可直接顯影，不受章內編號限制。
- 已解鎖但仍有關鍵劇本的小節只顯示「尚未完成」；後續小節可以反過來開啟它的新內容。
- 滿足線索時，顯影液從底片邊緣滲入，地點影像逐漸浮現。
- 解鎖演出最後不是金色寶箱光，而是黃銅夾扣「喀」一聲鬆開，底片被推入可選軌道。

### 5.3 BOSS 小節

BOSS 小節稱為「終局阻影」，不是「邪惡巢穴」。

- 底片上有一道人形、怪物或不明物擋在主角與光源之間。
- 普通人 BOSS 保留完整人類肖像與關係註記，不能因為是 BOSS 就自動怪物化。
- 使徒 BOSS 可以與某位神祇使用相近材質，但構圖方向和主角互相衝突。
- 怪物 BOSS 可以採解剖圖、失敗顯影與肉體重曝，但仍需表達它與主角成長的關係。
- 解鎖時只顯示「阻影已具名」或其劇情稱呼，不使用善惡判定。

## 6. 神祇傾向的視覺系統

神祇不能只靠換一個代表色區分。每位神祇應有一套完整的視覺語法：

```js
const deityArtProfile = {
  id: "deity_id",
  desireKeywords: ["信念或渴望關鍵詞"],
  accentColor: "#色彩",
  material: "金屬、蠟、皮革、玻璃、煙、血、織物等",
  geometry: "對稱、放射、纏繞、切割、缺失等",
  motion: "收緊、滲透、呼吸、碎裂、倒流等",
  sound: "代表聲響",
  portraitEffect: "如何影響主角肖像而不抹除角色本身",
};
```

### 6.1 顯示階段

1. **尚未辨認**：肖像附近只有不穩定污漬，右側顯示「某種凝視」。
2. **傾向形成**：反覆選擇使一種材質與構圖變得明顯，顯示渴望關鍵詞。
3. **神名揭露**：劇情正式接觸後才顯示神名、符號與完整視覺語法。
4. **形狀完成**：章結局時肖像形成該路線的最終構圖，但主角臉、既有身分與核心特徵仍然可辨認。

神祇影響應像顯影在角色周圍與身上，而不是把固定主角換成另一個無關人物。

### 6.2 不使用善惡色彩邏輯

- 白色不必代表善良。
- 紅色不必代表邪惡。
- 柔和暖色也可能屬於控制、依賴或吞噬。
- 尖銳冷色也可能屬於自由、誠實或自我犧牲。
- 玩家看到的是渴望正在形成，不是系統替選擇打道德分數。

## 7. 死亡回歸演出

死亡後的章節 UI 演出：

1. 主角肖像突然過曝，面孔被白光暫時抹除。
2. 本輪小節玻璃底片依序出現裂痕。
3. 道具標本盤被抽走，留下乾掉的血跡與物品輪廓。
4. 一枚巨大的官僚章落下：`未達預期／退回重塑`。
5. 神龕關閉，再次打開時換上一片新的主角底片。
6. 新肖像仍是同一個人，但本輪小節只剩第一片可以顯影。
7. 玩家已讀檔案以底片邊緣的殘影保留，並標示為「輪迴外紀錄」，不算角色當輪記憶。

黑色幽默可以來自神祇把死亡當成例行品質檢查：

- `死因已收件`
- `人格塑形不足`
- `本次信念濃度未達標準`
- `請重新活一次`

這些文字適合偶爾隨機出現，不要每次死亡都塞滿笑話，避免削弱真正悲劇性的死亡。

## 8. 血腥、腥羶與溫情的介面控制

### 8.1 全域 UI

全域章節 UI 以煤灰、暗房化學液、舊紙、黃銅與乾涸血跡為主，保持資訊清楚。不要讓整個介面長時間充滿活動內臟或大量裸露，否則所有章節會失去差異。

### 8.2 章節覆寫

每章可在共同框架上增加自己的局部材質：

- 肉體恐怖章：縫線、解剖註記、皮膚般的感光膜。
- 慾望與權力章：紅絨、香水油痕、蕾絲、咬痕、過度貼近的雙人曝光。
- 工業暴力章：油污、齒輪壓痕、工傷照片與金屬粉末。
- 宗教狂熱章：聖牌、香灰、被反覆刮除的禱文與不完整光環。
- 少數溫馨章節或小節：完整照片、未破損紙邊、穩定琥珀燈光與沒有被污染的手寫字。

溫馨畫面越少，越不需要額外加金光或愛心；讓它成為少數「沒有被弄髒的東西」即可產生力量。

## 9. 聲音與動態

- 選擇章節：木抽屜摩擦、相框輕碰牆面、遠處快門聲。
- 打開章節：神龕鉸鏈、濕玻璃被放上黃銅軌道。
- 線索解鎖：顯影液流動、鋼筆劃過紙面、暗紅線被拉緊。
- 神祇傾向變化：使用該神祇自己的代表聲響，不播放善惡判定音效。
- BOSS 解鎖：環境聲短暫消失，阻影先出現在主角肖像倒影中，再顯現在底片上。
- 死亡：快門、玻璃裂聲、沉重印章；不使用一般街機式失敗音樂。
- 支援減少動態模式，將過曝、流液與破裂改成短暫淡化和靜態裂紋。

## 10. 其他可用的章節原型

### 10.1 神祇解剖圖譜

將每位主角畫成一張維多利亞解剖學圖，小節是不同器官或創傷頁，選擇讓神祇符號沿血管生長。

- 優點：血腥、信念塑形與肉體變化非常直接。
- 缺點：容易讓所有路線都看起來像肉體神祇，不利於表現抽象、溫柔或社會性的渴望。

### 10.2 萬神劇院

章節是舞台劇目，主角是固定演員，神祇坐在黑暗觀眾席；小節是節目單上的不同場景。

- 優點：黑色幽默、腥羶、誇張暴力與維多利亞娛樂文化都很適合。
- 缺點：容易把神祇表現成單純操控玩家的外部觀眾，弱化「神祇反映玩家渴望」的核心。

### 10.3 無盡葬儀名冊

章節是一冊殯葬業者名冊，每次死亡都新增死亡證明與荒謬退件理由。

- 優點：死亡循環與官僚黑色幽默極強。
- 缺點：主角選擇、神祇傾向與多樣章節場景不如玻璃底片直觀。

正式方向建議以「未完成聖徒陳列室」為主，吸收「無盡葬儀名冊」的死亡退件章，以及少量「神祇解剖圖譜」的章節局部材質。

## 11. 美術驗收原則

- 玩家能辨認這是死亡循環與神祇觀測空間，而不只是一個普通任務列表。
- UI 清楚區分章、小節與小節內 13 事件點。
- 主角固定個性與身分始終比神祇特效更優先，不能被路線皮膚完全取代。
- 神祇傾向沒有善惡色條，也不以天使／惡魔的簡化圖示代替。
- 角色死亡後失憶，但 UI 永久檔案的存在有「輪迴外紀錄」作為敘事依據。
- BOSS 即使是普通人也能成立，畫面不會先把所有 BOSS 標記成邪惡怪物。
- 黑色幽默不覆蓋每個死亡與悲劇場面；溫馨片段不被強迫加上反諷。
- 桌面與手機版都能看清主角、故事時期、可玩小節、下一線索方向、神祇傾向與死亡風險。
