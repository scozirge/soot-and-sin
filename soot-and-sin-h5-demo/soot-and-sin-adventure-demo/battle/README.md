# 整合冒險版 — 戰鬥事件

由上一層 `../index.html` 進入。此版本會讀取共用生命、醫療物資與搜索時暫存的戰利品；獨立戰鬥原型位於 `../../soot-and-sin-event-prototypes/battle-event/index.html`。

- 惡魔行動倒數為 14／20／30 秒，結束後攻擊並開始下一個行動。
- 惡魔每次會公開選擇主角或 NPC 同行者 Morrow 作為攻擊目標。
- Morrow 不是可玩主角，會自主攻擊；被鎖定時會在攻擊後改為防禦。
- 玩家行動耗時為 2–6 秒；完成後可立刻再出牌。
- 攻擊要選擇部位，部位命中率與傷害倍率會在攻擊後揭露。
- 武器會保持選取，攻擊完成後可直接再點其他部位。
- 防禦與閃避會鎖定操作直到惡魔出手；若怪物不是攻擊或剩餘時間不足則不能使用。
- 次數耗盡的道具會從行動列移除。
- 短柄斧可用 3 次、燧發手槍可用 1 次；肉搏、閃避與防禦不會耗盡。
- 行動列可水平拖曳；攻擊牌點選部位後立即出牌，防禦與閃避點牌即執行。
- 正式規格中，擊殺惡魔後的戰利品只交由玩家選擇並整理至個人背包。
- NPC 同行者不會選取、搶奪或分配戰利品，也不會與玩家交易。
- 戰鬥中只有醫療道具能回血；同種道具堆疊後會累加使用次數。
- 怪物肉屬於食物，只能在休息階段回血，因此不會出現在戰鬥行動列。
- 利爪是一次性高傷害武器，怪物首級只作為可出售戰利品。
