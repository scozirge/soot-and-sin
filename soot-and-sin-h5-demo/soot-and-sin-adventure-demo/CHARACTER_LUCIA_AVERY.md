# 露西亞・艾弗里（Lucia Avery）角色設定

## 1. 身分與背景

- 露西亞是古老皇室的後代，具有高貴血統；但在後末日時代，皇室身分已沒有太大的現實意義。
- 她是後末日世界中少數仍能上學、接受高等教育的知識分子。
- 她屬於「胡桃木」生存組織中的一個小家庭。
- 在學習以外的時間，她會跟隨另一名組織成員前往車站，搜索能帶回據點使用的物資。

## 2. 個性

- 沉穩、聰明且善於學習。
- 對未知事物與知識具有強烈的探索慾望。
- 態度正面，具有領導魅力。
- 精神力強大，傾向以積極、正向的方式面對困境。

## 3. 初始專屬天賦

### 魅力

- 說服成功率額外增加 5 個百分點。
- 進入安全區事件時，夥伴會提供 1 件食物或醫療用品。

這項天賦永久屬於露西亞，不會因死亡或章節重置而失去。露西亞由魅力屬性提供的基礎說服成功率為 24%；加上天賦後，起始說服成功率為 29%。

## 4. 附屬性

| 屬性 | 數值 |
| --- | ---: |
| 體力 | 4 |
| 力量 | 4 |
| 搜查 | 7 |
| 魅力 | 8 |

## 5. 主要屬性

| 主要屬性 | 計算 | 最終數值 |
| --- | --- | ---: |
| 生命 | `50 + 體力 × 5` | 70 |
| 背包格 | `30 + 體力 × 1` | 34 |
| 肉搏傷害加成 | `力量 × 5%` | +20% |
| 非銀幣商品交易費用折扣 | `魅力 × 3%` | 24% |
| 說服成功率（屬性基礎值） | `魅力 × 3%` | 24% |

初始專屬天賦「魅力」另提供 5 個百分點，因此露西亞的起始說服成功率為 29%。搜查為 7，但搜查屬性的實際換算與搜尋物資規則尚待規劃。
