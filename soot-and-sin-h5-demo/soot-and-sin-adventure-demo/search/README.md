# 整合冒險版 — 搜索事件

由上一層 `../index.html` 進入；獨立搜索原型位於 `../../soot-and-sin-event-prototypes/search-event/index.html`。

流程：進入場景 → 決定搜索 → 黑霧幻燈片判定 → 結果與物品確認 → 繼續深入／整理物資／轉入戰鬥事件。

幻燈片會依當次機率生成物資、精品、神器、怪物、強大怪物與使徒；停在中央的底片就是實際結果。搜索不會落空，只會取得物資或進入戰鬥。

同名物資會堆疊數量。食物只能在藏匿處回血，不會出現在戰鬥中；武器與醫療用品會成為戰鬥行動。

所有搜索物資都交由玩家自己的背包處理，不存在隊友搶奪、公共分配或道具交易。

搜索物資池分成武器、食物與醫療用品三類，搜索結束後下一個輪巡事件固定為戰鬥。

正常停止會送出 `scavenge-complete`；遭遇怪物則送出 `battle-event-requested`，並把待領物資存入 `window.pendingScavengeCombat`。
